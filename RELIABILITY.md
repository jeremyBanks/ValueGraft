# RELIABILITY.md — direct-local checks

The cloud-era prevention manual is archived under the slug
`powered-v13-pre-local-reliability`.

- Print and persist model ID, resolved revision, weight-blob/config/tokenizer/
  template hashes, quantization, dtype inventory, MLX versions, geometry, code
  commit, dirty state, device, and output path before outcomes.
- L0/L3 identity and the applied L5 sham must pass on the exact model/config.
- Persist carrier attempts, accepted token IDs/text/seeds, source/fresh caches
  needed for controls, every arm score, and hashes before advancing cases.
- One MLX process at a time. Measure the first valid case before projecting the
  48-case wall time. Check valid N and elapsed time every four conversations.
- Complete-history review precedes treatment. Reviewer assignments and reasons
  are saved; the subject model is never its own judge.
- An applied placebo is available only if it passes the frozen actual-dtype
  geometry criteria. Unavailable remains unavailable.
- Exact C/W target strings and token IDs are bound in each fixture. Scores are
  teacher-forced only over declared answer-content tokens.
- Unique output directories and exclusive per-case writes prevent overwrite.
  Partial, failed, rejected, and unavailable artifacts are retained.
- Any change to the estimand, selection, render distribution, eligibility, or
  control rule after outcomes creates a separately labeled study; it does not
  revise v1.
