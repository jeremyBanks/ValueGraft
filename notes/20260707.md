_The day spanned the formal closure of the synthetic chain-arm agent experiment,
an extensive mechanistic side-investigation using a newly available
interpretability tool (the "J-lens"), the drafting and repeated revision of the
project's public report around its headline semantic-richness finding, and —
late in the day — the discovery of an unresolved contradiction between a new
bounding experiment and the paper's own published numbers, which halted all
downstream work pending a live reproduction check._

**Chain-arm closure and the tau2 decision.** The synthetic chain-task grid (4
seeds × 5 arms) completed and confirmed that naive full-strength grafting
(α=1.0) can collapse an otherwise-solvable task, and that per-layer tuning
("champion") eliminates that collapse — but also that the Compacted baseline
never failed on these chains, so there was no compaction damage for grafting to
visibly repair (a ceiling effect). A dedicated recall probe intended to detect
subtler damage was found to be invalid for this task tier, since its hardcoded
questions referenced constants belonging to an earlier task type. With both the
recall channel and the effort-proxy channel ruled out, the chain-arm line was
formally closed: real but narrow evidence (tuning cures instability) plus a
confirmed null (no compaction damage on this task set). Compute was fully torn
down, and three paths forward — harder cross-dependent chains, adopting the tau2
benchmark (contingent on a ~$3 pilot and user funding), or writing up on
existing strength — were left as an open decision, not resolved by end of day.

**Mechanistic investigation via J-lens.** A separate branch of work, prompted by
a handoff note describing Anthropic's newly published "global workspace" /
Jacobian-lens (J-lens) research, built an isolated `jlens_boundary_probe/`
directory to explore whether this readout tool could give internal-state
evidence for the project's compaction hypothesis, using Qwen3.6-27B (the model
for which pre-fitted lens weights exist, distinct from the project's primary 30B
subject model). Early demos (a synthetic toy example, a Pokémon-memory
conversation, an ordinary planning conversation, a full all-token/all-layer
sweep, and a SWE-Gym next-action probe) established a qualitative pattern: the
same visible summary token reads differently depending on whether it was written
under the original conversation or freshly re-encoded from a compacted summary —
e.g., a stale permit code read as "obsolete" under write-time context versus a
generic civic label when freshly encoded. A next-token control clarified that
this is not merely next-token prediction dressed up: layer 48 showed low overlap
with ordinary next-token candidates while layer 62 was much closer to
continuation behavior, making layer 48 the more semantically distinct readout
depth.

A significant correction followed mid-cycle: these two-state (write-time vs.
fresh) comparisons only show that a state gap exists after compaction — they say
nothing about whether the project's grafting intervention closes it, because the
earlier probe script had silently failed to capture the grafted state at all.
This was treated as a real methodological lapse and fixed by building genuine
three/four-condition probes (full context, fresh compacted, alpha-zero sanity
control, and grafted compacted), validated by an independent schema check after
an earlier incident where surprising JSON structure was patched around with ad
hoc queries instead of being verified against the producing code — now a
standing rule for the directory. The corrected intervention probes showed
alpha-zero exactly reproduces the fresh baseline (a working sanity gate),
aligned value-grafting produces small, alignment-sensitive shifts toward the
full-context readout, and a shifted (misaligned) control performs worse — but on
a harsher "sparse challenge" setting, where summaries omitted the relation being
tested rather than just paraphrasing it, grafting produced no measurable
recovery at all. The honest reframing adopted from this: value grafting reduces
reinterpretation error around facts a summary still carries, but does not
reconstruct facts a summary aggressively drops.

**Headline finding and report arc.** The project's central empirical result,
informally labeled F1, is a dissociation: at 30B, value grafting recovers
meaning on `sense` (+12pp) and `referent` (+10pp) probes relative to plain
compaction, but shows a null effect (+2pp) on `stance`, where a good summary
already preserves the disposition. This pattern — effect size tracking where
compaction actually did damage — was corroborated by an independent
teacher-forced logprob metric (smaller magnitude, same direction) and survived a
stricter scoring cut, but did not replicate at 4B scale, and a same-model check
on Qwen3.6-27B reproduced `sense`/`stance` but found `referent` flat. A
public-facing report was drafted through a disciplined multi-pass process
(outline against a fixed narrative spine, adversarial critics for
over-justification/accuracy/accessibility/gaps, verified exhibit integrity),
pushed, then substantially revised twice more: once to add concrete verbatim
transcript exhibits (a fabricated consultant citation, a confidently asserted
but unsupported preference, several referent confabulations) after the first
version was judged too abstract, and again to incorporate the J-lens work —
which required rebalancing the report so the lens remained a secondary,
corroborating instrument rather than competing with the primary grafting result,
and fixing overloaded "lens" terminology across the document (logit lens, tuned
lens, and J-lens had been conflated).

**K/V axis and the free-generation check.** A per-layer key-grafting sweep found
no rescue effect for semantic-phrase referent recovery at any tested layer,
narrowing the mechanism claim to value grafting specifically; a secondary, less
rigorous finding that key-grafting might help short identifier-style targets was
judged statistically underpowered and deferred to a future pre-registered test.
A carefully pre-registered free-generation divergence probe (designed to find
where grafted and compacted trajectories fork, with three outcome buckets fixed
in advance to prevent post-hoc reframing of a null result) ran cleanly negative
— no case showed a clear fork toward the correct concept — reinforcing rather
than undermining the "real but subtle effect" framing.

**Unresolved risk: an effect-bound discrepancy.** A new placebo-controlled
bounding experiment, intended to give the lens story a defensible number,
produced results that could not be reconciled with the paper's already-published
gap-closure figures when computed from the same 43 cases and same model: only
37% of cases showed graft beating compaction versus the published 64–81%. The
current working hypothesis is a bug in the newer probe's teacher-forcing
implementation, since the original scoring script still reproduces its own
published numbers on the same inputs — but this is unconfirmed. All downstream
work, including a planned cross-architecture generalization sweep (across
several current ~24–35B models, with MLA architectures like DeepSeek excluded as
likely structurally incompatible), was explicitly paused pending a live
reproduction of the original result.

**Other developments.** A provenance-tracking incident was resolved as precisely
as the data allowed: git commit trailers had mislabeled roughly six hours of
work as one model when a clean handoff to another had already occurred; the
exact transcript boundary was recovered, but the triggering cause (quota
exhaustion vs. a system-level reroute) remains only suggestively evidenced and
was not investigated further per user instruction. Repository hygiene work
relocated obsolete top-level planning documents into a dated `docs/` convention
and established that each working directory's README should hold its current
best output. A separate, self-contained interpretability tangent examined how
the subject model handles a historically and politically sensitive topic,
finding language- and framing-dependent narrative routing rather than simple
refusal; this was deliberately isolated in its own neutrally-named directory,
kept out of the main pipeline, and treated as a standalone behavioral curiosity
rather than part of the core research line.

**Open questions and next actions.** The most consequential unresolved item is
the gap-closure discrepancy: a live re-run of the original scoring script on 30B
must confirm or overturn the published headline numbers before any further
mechanistic or cross-architecture work resumes. Behind that gate: whether to
invest in harder chain tasks or tau2 for agent-style evidence, whether the
cross-architecture sweep can proceed once trust in the measurement apparatus is
restored, and how much further the K/V or free-generation lens threads are worth
pursuing given consistently subtle or null results.
