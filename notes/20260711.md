_The UTC day completed a clean, provider-configurable archive rebuild and
substantially narrowed the ValueGraft scientific conclusions. The repository
supports latent continuity as a meaningful question, but not a robust benefit
from naive post-prefill, value-only grafting._

**Participants/contributors:** User; gpt-5.6-sol-xhigh; claude-opus-4-8.

The archive workflow is now consolidated behind one command with provider/model
propagation across conversation, daily, monthly, yearly, and archive summaries.
It supports ephemeral or nonpersistent workers, selective subagent-final
inclusion, referent-level filtering, deterministic contributor provenance,
model-based filenames, and recursive rollups. A clean Luna rebuild generated and
validated 55/55 conversation notes, preserved 269 opaque source IDs, produced
participant/model metadata in all 10 rollups, and passed 56 tests. Prompt and
implementation fixes addressed custom-command argument swallowing,
summary-worker self-ingestion, provenance placement, filename identity
conflation, and atomic replacement safety.

The scientific record was corrected in interpretation, though the paper remains
held for one authorized holistic revision. The held-out synthetic result is not
a homogeneous null: Qwen-rendered conversation bodies show a positive effect
while Claude-authored bodies show a negative effect, yielding a pooled near-zero
result whose weighting and source confounding limit generalization. Three of
four compression-sweep conditions appear methodologically invalid because the
reconstructed write-time state may use a different summary request from the one
used during generation. The graft also affects both summary and retained-tail
regions, so existing results cannot be attributed specifically to summary-state
retention.

The strongest current coding result is a small in-domain per-layer-tuned
improvement, approximately +0.0126 nats/token across 143 trajectories and
+0.0135 on the out-of-sample subset. This remains a teacher-forced next-action
likelihood proxy on imported GPT-4o/Claude trajectories, not agent task success:
no patches were applied and no tests were executed. The fixed-strength graft is
heterogeneous—positive on the original 75 trajectories, null on an independent
98, and pooled borderline-null at roughly +0.0053—so the tuned result requires
strict external confirmation. Existing SWE artifacts also lack exact generated
summaries, token IDs, complete render context, dataset hashes, and code-commit
provenance.

Methodological terminology should persist: raw E-B is a log-probability
difference in nats/token, not a mathematically bounded quantity;
“content-specific” comparisons against unmatched shuffled/Gaussian controls do
not establish semantic recovery; and values are contextual projections, not
position-free memory slots. The repository supports a qualified negative result
for this exact intervention, not a general negative result about latent state
continuity. Recent external work provides direct motivation for comparing
coherent retained state with identical-text restart.

The next research stage should prioritize causal separation over further broad
tuning:

- Compare coherent original K+V state with identical-text fresh restart,
  wrong-history controls, K-only/V-only variants, summary-only versus tail-only
  grafts, and treatment-delta-matched placebos.
- Re-run synthetic source and compression effects with exact request/state
  provenance and paired source renders.
- Rescore existing SWE artifacts at zero cost, then use one frozen champion for
  untouched confirmation.
- Run a small capability-matched, model-native agent pilot with common-prefix
  forks, workspace snapshots, ordinary compaction, coherent retention, and
  actual tests or resolved patches.
- Follow staged $0/$50/$100/$200 gates; do not fund another broad architecture,
  alpha, or layer sweep before the causal and artifact-reproducibility
  prerequisites pass.

Outstanding risks are source confounding, incomplete render provenance,
unmatched controls, model-native capability gaps, and the possibility that the
coding signal is imitation-specific rather than agentic. The paper and external
publication should remain paused until these corrections are incorporated in a
single holistic pass.
