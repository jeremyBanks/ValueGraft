## Research conclusions

The strongest defensible scientific synthesis is now:

> Generation-time KV state can preserve task-relevant information that is absent
> from, or not recoverable by re-encoding, compacted text. This repository has
> not shown that a training-free, post-prefill replacement of fresh values with
> historical aligned values reliably converts that information into better
> semantic recovery or agent performance.

Key corrections and findings:

- The held-out synthetic corpus is not homogeneous or fully native to the test
  model. c07–c12 use Qwen3-4B 4-bit-rendered bodies, while c13–c24 are
  Claude/Fable-authored; only the summary was generated by the Qwen3-30B test
  model.
- The apparent pooled synthetic null hides a source-conditional sign reversal:
  approximately +0.120 nats/token for c07–c12 and −0.050 for c13–c24, yielding a
  pooled value near −0.003. This is exploratory and confounded with source and
  other corpus properties, but it cannot be described as a homogeneous clean
  null.
- The compression sweep is methodologically suspect: three levels appear to
  reconstruct write-time state under a request different from the one used to
  generate the summary. Only the realistic condition is currently supported as
  request-consistent; the code path should be verified before finalizing this
  claim.
- The graft affects both summary and retained-tail positions, not summary
  positions alone. Existing results therefore cannot attribute effects
  specifically to summary-state retention; a summary-only/tail-only factorial is
  required.
- Shuffled and Gaussian controls are not matched to the treatment delta’s norm
  or covariance. Correct values being less harmful than mismatched values
  demonstrates alignment or compatibility, but does not by itself establish
  recovery of hidden-history semantics.
- The original fixed SWE-Gym positive did not independently replicate. Across
  173 unique trajectories, the pooled estimate is approximately +0.0053
  nats/token with a bootstrap interval spanning zero. A per-layer champion is
  positive on its internal held-out split, around +0.0117 to +0.0135 depending
  on the final aggregation, but does not clearly beat the fixed scalar graft and
  remains an offline teacher-action proxy.
- SWE-Gym uses successful foreign trajectories, reportedly from GPT-4o and
  Claude 3.5 Sonnet, rather than Qwen-native agent behavior. No patch is
  applied, test is run, or task success measured; action-match scoring is coarse
  and may ignore edit contents.
- The broader project therefore supports a narrow, conditional coding-domain
  lead—not an agent-performance result or universal value-grafting benefit.

## Methodological interpretations to preserve

The most useful distinction is between:

1. information existing in coherent generation-time state;
2. information specific to the correct hidden history;
3. benefit from retaining a coherent full state; and
4. benefit from transplanting old values into fresh keys and upper-layer
   representations.

The current intervention primarily tests the fourth and may damage the trained
K/V joint representation. Values are contextual activations, not position-free
memory payloads, and post-hoc grafting can leave downstream cached
representations internally inconsistent.

The speculative mechanism note proposes that fresh values are already a largely
re-derivable readout of the summary, so correct grafts often avoid the harm
caused by wrong grafts without adding useful signal. Gradient-projection
analysis of write-time versus fresh values is identified as the most decisive
test of this explanation; it remains a hypothesis, not a finding.

## Repository and workflow developments

The archive rebuild is now consolidated behind one provider-configurable command
supporting Luna or Claude, shared extraction/summarization/normalization/rollup
stages, and propagation of provider/model settings through all summary layers.
It uses ephemeral or nonpersistent workers, explicit summary-worker exclusion,
narrow inclusion of final assistant subagent assessments, chronological
insertion of those finals, contributor provenance at every layer, and
referent-level filtering for excluded topics.

Filename identity, participant identity, and opaque source provenance are now
separated. Filenames contain compact user/model identifiers only; task labels,
opaque IDs, subagent counts, and byte-limit machinery are excluded. The
corrected implementation passed 57 repository tests, and custom-command dry-run
behavior was verified.

The clean Luna rebuild has generated and validated only the first three of 55
replacement conversation notes. Existing notes and the manifest remain untouched
pending completion and validation of all candidates, followed by an atomic swap
and recursive rollup regeneration.

- Keep external publication and paper edits on hold until the final README
  receives one holistic correction pass covering provenance, source-stratified
  results, compression validity, graft-region wording, placebo limitations, SWE
  scope, and reproducibility metadata.
- Verify the compression request-consistency issue directly in code before
  treating it as settled.
- Preserve exact SWE summaries, token IDs, contexts, alignments, dataset hashes,
  and code commits in future renders; current artifacts are insufficient for
  exact replay.
- Prioritize a small causal experiment comparing coherent original K+V,
  identical-text fresh restart, wrong-history restart, old-V/fresh-K graft, and
  treatment-delta-matched placebo.
- Use summary-only and tail-only interventions, then test a capability-matched
  model with an actual compaction gap before authorizing larger compute.
- Avoid further broad alpha/head/layer/architecture searches, unmatched
  placebos, imported next-action scoring without execution, or live-agent work
  before the offline apparatus and capability gates pass.
- Complete and validate all 55 archive candidates before any atomic replacement;
  retain the current notes as the rollback state.
