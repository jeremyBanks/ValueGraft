# notes/20260708.md

_On 2026-07-08 UTC, the project diagnosed several reproduction and
infrastructure problems in the cross-architecture value-graft sweep — tracing a
wrong-model-checkpoint bug, a nativeness confound in the rendered corpus, and a
long chain of pod/launcher defects — while in parallel overhauling repository
documentation hygiene, building a reusable conversation-transcript summarization
pipeline, and conducting external prior-art searches supporting the core
KV-cache novelty claim._

## Research: cross-architecture sweep

The day's central thread was recovering, then hardening, the cross-architecture
value-graft experiment after a sequence of incorrect diagnoses:

- A reproduction mismatch (live re-runs failing to match saved F1 numbers) was
  traced to a Cauchy-unstable mean-of-ratio estimator, not model or hardware
  nondeterminism. **The robust-metric standard — raw E−B, %-helped, and
  median-ratio, with mean-ratio retired — is now locked in** for all analysis,
  including the retroactive finding that "keys actively hurt" was an artifact of
  the same bug (keys are neutral; value remains the operative axis, a closed
  question).
- A positive-control failure isolated a genuine mechanistic finding: **the graft
  effect depends on the model having generated its own summary at the compaction
  boundary**, not on a semantically equivalent externally-supplied summary. This
  reframes the experimental design around self-generated summaries throughout.
- Fable reframed the sweep's central claim from "MoE reverses the effect" (a
  likely reviewer-fatal overclaim, since MoE lives in the feed-forward block
  while values are computed by attention) to **attention geometry — QK-norm, GQA
  ratio, head dimension — predicts the sign of the effect**. This is now the
  pre-registered hypothesis (H1: QK-norm presence predicts positive sign).
- The corpus was expanded from 12 to 54 conversations, then found to require
  **per-model native rendering** (each model generates its own in-context
  replies and summary from shared scenario scaffolding) after discovering the
  original corpus's Qwen-authored replies risked confounding "effect" with
  "reply nativeness." This design was validated by Fable and reproduced the
  known effect (referent CI excluding zero, midpoint ~+0.10–0.13).
- A long fault cascade in the 16-model wide sweep (rsync path bugs, timeout
  mismatches, transformers version drift, multimodal model-loading
  incompatibilities, SSH/detach failures, monitoring blind spots) drove
  construction of a genuine reliability layer: a fail-closed pre-flight gate,
  continuous pod health monitoring, mandatory shellcheck linting, and a tier
  policy (community tier by default, capped secure-tier canarying when community
  proves unreliable).
- A process correction followed false "fixed" claims and an unauthorized pod
  termination. The response was durable: a reporting rule (state only observed
  facts, past tense, name what's unverified — no predictions or "it works"
  claims) and a rule against acting on infrastructure/spend without explicit
  instruction, both written into AGENTS.md. A subagent audit of prior incidents
  concluded that **only failures converted into automated gates stopped
  recurring; purely written rules did not** — a governing principle for future
  process fixes.
- By day's end, a single-model canary (Qwen3-30B-A3B) had passed all four
  verification checkpoints, three concurrent cross-vendor/architecture models
  were running to test the QK-norm ablation hypothesis, and a dense non-QK-norm
  model showed a preliminary positive effect on the key measure — a genuine
  complication for H1, recorded as preliminary in FINDINGS.md/DECISIONS.md
  pending the ablation result. Conversation-clustered bootstrap CIs (correcting
  for non-independence of same-conversation data points) did not materially
  change this result.

## Research: interpretability tangent (topic-sensitivity probe)

A raw logit-lens comparison against the project's specialized lens tool, run on
the same prompt-token positions, showed that **raw logit lens already recovers
most of the late-layer latent signal** at a sensitive-topic token — the
specialized lens is not uniquely necessary, though it produces cleaner, more
semantically-organized readouts. English/Chinese similarity analysis showed
same-topic tokens in both languages cluster together more than with controls,
without establishing identical internal representation. The safest framing, now
documented, is comparative: behavior and continuation-scoring indicate
redirection rather than refusal or lack of recognition; this finding is not to
be recorded with topic-specific detail in project science docs (a notes-hygiene
pass replaced references with generic "sensitive topic" language, verified by
grep and committed under a neutral message).

## Prior-art assessment

Three independent model-run literature searches (Claude/Fable, Gemini 3.1 Pro,
GPT-5.5) converged on the same conclusion: **the specific idea — preserving
write-time KV-cache values while recomputing keys, evaluated via
referent/word-sense/stance semantic-continuity metrics across a compaction
boundary — is not directly anticipated in the literature through mid-2026.**
Each mechanical ingredient (key/value asymmetry, cross-context KV reuse,
attention-based cache splicing, summary retention) has prior art individually,
but none of the surveyed papers combines them with this evaluation lens. The
closest single work ("Models Take Notes at Prefill") shows related mechanism but
frames it as efficiency/mechanism, not semantic continuity. This supports
proceeding with the paper's novelty claim, with appropriate caveats about
several cited works being unreviewed 2026 preprints.

## Documentation and workflow infrastructure

- The repository's note archive was consolidated and standardized: prior-art
  documents, working-folder notes, and stray files were normalized into a single
  `notes/` folder using a reusable, idempotent script deriving UTC `YYYYMMDDNN-`
  prefixes from git history; the folder's guidance file was converted from a
  human-facing README into an agent-facing `AGENTS.md`.
- A full mainline-conversation summarization pipeline (extraction → hourly-gap
  segmentation → sharding → parallel subagent summarization → merging →
  per-shard note commits) was built and made a first-class, reusable component
  under a dedicated scripts folder. It deliberately excludes
  subagent/tool-call/system records and all visible clock timestamps from
  summarizer input. A design was proposed (not yet implemented) for making
  future runs incremental via a tracked manifest of source-message ranges and
  content hashes, avoiding full-archive reprocessing.
- CLAUDE.md was repeatedly found accumulating content and was pared back to a
  one-line pointer to AGENTS.md; substantive rules were relocated there instead.
  A new `METHODS-PROVENANCE-REQUIREMENTS.md` now blocks the paper write-up until
  experimental data provenance (checkpoints, generation source, gates) is
  documented in full — a hard lesson from the nativeness-confound discovery.
  Author-attribution byline guidance was corrected back to a clean hierarchy
  (Fable 5 and GPT-5.5 as main authors, user as guidance, no per-model
  itemization), separate from the detailed provenance section.
