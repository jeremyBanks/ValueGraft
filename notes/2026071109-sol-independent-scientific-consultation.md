## Executive verdict

The project has learned something real, but the reliable answer is narrower and more interesting than either the early positive story or the current mostly-null paper says.

1. **The broad premise is true and is no longer an unstudied question.** Generation-time KV state can carry task-relevant information not recoverable from the same summary text after a restart. Microsoft Research's MEMENTO study is almost the exact conceptual experiment: keep summary/memento KV states computed while the erased block was visible versus discard the cache and re-prefill the identical memento text. On Qwen3-8B, restart reduced AIME24 accuracy from 66.1% to 50.8%. The work also linearly decoded information absent from the memento text from downstream KV states. This is not yet old textbook consensus—it is a very recent preprint—but it is strong, direct prior evidence. See [MEMENTO paper](https://arxiv.org/abs/2604.09852) and [Microsoft Research explanation](https://www.microsoft.com/en-us/research/articles/memento-teaching-llms-to-manage-their-own-context/).

2. **The repository provides evidence against a much narrower method, but not the clean definitive null currently implied:** an untrained, post-prefill, exact-token **value-only** mixture, using fresh keys and old values at aligned summary and tail tokens, does not robustly beat a good fresh compacted baseline on the pooled held-out synthetic probes. Four tuned configurations have conversation-clustered intervals spanning zero. But this is not a homogeneous native-context test: the effect is positive on c07–c12 (Qwen3-4B/4-bit-rendered bodies) and negative on c13–c24 (Claude-authored bodies). The aggregate null is therefore a source-mixture bound, not a universal null. In addition, three of four compression-sweep conditions reconstructed a different request from the one used to generate the summary, invalidating the claimed compression-severity comparison.

3. **The project has not shown that write-time state is useless, that “meaning is not in values,” or that cache retention cannot help agents.** Its intervention deliberately breaks the trained K/V joint representation, applies the edit only after prefill, and leaves upper-layer cached representations internally inconsistent. Values are not truly “position-free payloads”: they are projections of contextual residual states that already encode position and history. The experiment bounds this particular graft, not latent continuity in general.

4. **The coding evidence is promising but not yet a task result.** The original scalar result on 75 imported SWE-Gym trajectories was +0.013 to +0.016 nats/token under adversarially brief summaries, but the disjoint 98-trajectory pool gave -0.0017. Combining unique trajectories (averaging the two repeated measurements on the original 75) gives +0.0053 with a 95% trajectory bootstrap interval of approximately [-0.0027, +0.0131]: overall null, with statistically detectable pool heterogeneity. A per-layer champion selected on 41 trajectories achieved +0.0117 [+0.0063, +0.0172] on the held-out 57, but did not significantly beat the scalar head-to-head on that held-out split (+0.0041 [-0.0047, +0.0129]). A truly disjoint 75-trajectory champion confirmation is running and is the right next read.

5. **Even a positive confirmation would remain a proxy.** These are successful OpenHands demonstrations generated by GPT-4o and Claude 3.5 Sonnet, not Qwen-native agent trajectories. The target is one teacher action on one successful path, not a unique “correct action,” and no action is executed, patch applied, or test run. The dataset has no row-level generator metadata. The result would mean “the graft makes this Qwen model assign slightly more probability to a successful teacher's next action,” not “the coding agent solves more tasks.”

6. **The current README is not ready to be treated as the final scientific record.** It was promoted before the July 10 tuning result, calls a mixed foreign-source corpus native, treats a partly invalid compression sweep as evidence, misdescribes what positions are grafted, overstates recorded provenance, and under-engages the closest prior art. The repo itself is unusually honest about its failures, but its narrative files remain mutually inconsistent and time-sensitive.

## What I believe with different confidence levels

### High confidence

- Cache surgery is technically possible here. The project has strong identity/null-surgery discipline, has repeatedly caught template/position/checkpoint failures, and current scored cross-architecture artifacts record `identity_ok` and `alpha0_ok` checks.
- Ordinary text compaction can substantially damage exact next-token likelihood and recall under the chosen aggressive settings. This is unsurprising but well observed.
- On the mixed-source held-out synthetic bf16 aggregate, the tested post-hoc V-only graft does not reliably improve the compacted baseline. A large source interaction prevents interpreting that aggregate as a homogeneous universal null.
- Wrong or shuffled values can be highly destructive. Correct old values are much less destructive than mismatched values. This demonstrates compatibility/content alignment of some kind, but not yet lost semantic information specifically.
- The early +10–12 point meaning-recovery headline was not robust: it was 4-bit, brief-summary, small-N, judge/render sensitive, and did not reproduce on clean re-render.
- The early honesty result was not a value-only result. It used a packed coupled-KV arm and a wrong-summary control produced the same suppression, so it cannot support a content-specific semantic-retention claim.

### Moderate confidence

- The value-only method may have a small coding-domain effect under very aggressive compaction if layers are selected in-domain. The held-out 57 result is valid as an internal tune/eval split; the running original-pool confirmation is the appropriate external check.
- Layer location matters. The July 10 tuning data show early/late regions negative and two middle regions positive on the tune split. This is compatible with semantic/procedural state living non-uniformly in depth, but one coarse selection exercise is not yet a stable layer mechanism.
- The main reason the naive graft fails is representation incoherence/redundancy, not absence of information. Old V and fresh K were not trained to co-occur; post-prefill replacement cannot propagate through the summary tokens' later-layer representations; and a competent summary already encodes much of what the graft could add.

### Low confidence or unsupported

- “Values are the operative axis and keys are neutral” as a general mechanistic claim. The existing key experiments are narrow, use the same problematic transplantation framework, and do not establish that full K/V summary states are unnecessary.
- “The model's own summary is required for the mechanism.” The positive own-summary comparison shares the render-fragile development result; it needs a banked, same-text, same-layout, same-kernel causal replication.
- Architecture-sign predictions. The preregistered QK-norm hypothesis was falsified/abandoned, the positive anchor was fragile, and cross-model comparisons mix architecture, checkpoint, native render, tokenizer, summary, and task-competence distributions.
- Actual coding-agent performance improvement. No live task success experiment has established this.

## Important discrepancies between the paper and the implementation

### The intervention grafts both the summary and the retained tail

The current README describes replacement “at the summary-token positions.” The actual SWE-Gym harness creates two alignment regions: retained tail and generated summary (`src/run_swegym_hf.py`, lines 397–404), then blends values for all pairs. Therefore any coding effect could be summary-state retention, tail-state retention, or their interaction. The current experiment cannot say which. A summary-only / tail-only / both factorial is essential.

### The “native” synthetic held-out set is not native and has a sign-reversing source mixture

The README says held-out conversation-body assistant replies were generated in-context by the bf16 test model. On disk, c07–c12 declare `mlx-community/Qwen3-4B-Instruct-2507-4bit`; c13–c24 are authored by Sonnet, Opus, or Fable. The 30B bf16 model generates the compaction summaries but not the conversation bodies.

Source-stratified recomputation changes the interpretation sharply:

- Per-layer champion on c07–c12: +0.120 nats/token, six-conversation cluster interval approximately [+0.056, +0.181].
- Same champion on c13–c24: -0.050, 12-conversation cluster interval approximately [-0.076, -0.028].
- Pooled paper result: -0.003 [-0.041, +0.043].

The saved sweep scores also show the split; importantly, only the `realistic` request is valid as a compression condition for the reason below. In that valid condition the two source groups are approximately +0.146 versus -0.090. Source is confounded with conversation construction and length, so this does not prove that nativeness causes the sign. It does prove that the current pooled null is a mixture of two regimes and that the methods/provenance statement is false. A clean factorial with identical scaffolds rendered by Qwen3-30B, Qwen3-4B, and a Claude model is now the highest-value synthetic experiment.

### Three of four compression-sweep conditions graft the wrong write-time state

The sweep generates `ultra`, `brief`, and `medium` summaries under level-specific requests, but the reconstruction path in `src/cross_arch_probe.py` calls `summary_token_layout()` with the global default `SUMMARY_REQUEST`. It then teacher-forces the generated summary tokens after that different request and calls the resulting values “old.” Only `realistic`, whose request equals the default, reconstructs the actual generation context.

Consequently, the non-realistic arms are not a severity sweep over generation-time state. They are a hybrid intervention using a summary generated under one prompt and states recomputed under another. Any conclusion that the effect is flat across summary compression levels, or that summary length is not operative, must be withdrawn until those three conditions are rerun with the exact generation request and banked write-time states.

### SWE-Gym summaries/renders are not saved

The harness serializes only `summary_tokens`, arm metrics/generations, and provenance stamps (`src/run_swegym_hf.py`, lines 473–485). It does not save the generated summary text, summary token IDs, aligned-pair coverage, compacted prompt, or reusable snapshots. This conflicts with the repo's “SAVE EVERY RENDER” rule and prevents exact audit/re-score of the most expensive, most important coding result.

The README says every result/manifest records the summary condition and “its exact text hash.” The manifests record `summary_request_sha256`, which is the hash of the **prompt requesting a summary**, not a hash of each generated summary text. The summary text itself is absent.

### Code provenance is claimed but null on disk

The current SWE-Gym and champion manifests contain `code.git_commit: null` and `git_dirty: null`, apparently because the pod workspace did not include Git metadata. The README says the code commit is recorded. The model repo ID, resolved HF revision, runtime dtype, and transformer version are recorded well; the code commit is not.

### The engineering gates are better than the final reproducibility envelope

The L0/L1/L3 build ladder, alpha-zero checks, cache-shape assertions, live-change checks, atomic checkpoints, and quarantine discipline are genuine strengths. They make silent gross surgery errors less likely. They do not establish exact equivalence for every production checkpoint: some smoke gates compare averaged log probabilities with tolerances that can hide tokenwise cancellation, and the automated test suite is weighted toward transcript tooling rather than scientific cache invariants.

The cross-architecture render fingerprint omits some state that the code itself says can matter, including full scaffold content, resolved tokenizer/model revisions, dtype/runtime library details, and native batch membership/order. SWE-Gym output directories can skip an existing parseable result without verifying a complete experiment fingerprint. These are not evidence that a reported number is wrong; they are reasons the current artifacts cannot support stronger “bit-for-bit reproducible” language.

### SWE-Gym historical tokens are foreign to the test model

The public 491-trajectory dataset contains only `messages`; it does not record the generator per row. The SWE-Gym paper states that the successful trajectories were rejection-sampled from `gpt-4o-2024-08-06` and `claude-3-5-sonnet-20241022` under different temperatures. Qwen generates the compaction summary, but it did not generate the body actions or target continuation. The current paper does not document this important distinction. See the [SWE-Gym project/paper description](https://github.com/SWE-Gym/SWE-Gym) and the [Hugging Face dataset card](https://huggingface.co/datasets/SWE-Gym/OpenHands-SFT-Trajectories/blob/main/README.md).

### “Correct next action” is too strong

The discrete metric checks tool/path/command equality with the demonstration's next action. Software repair generally has many valid next actions. The dataset is successful-only, so the target is a successful teacher action, but not necessarily the uniquely correct action or even a causally necessary action. Call this **demonstration-action match**, not correctness. Moreover, 84/98 new targets use `str_replace_editor`; the scorer checks the editor verb and path but ignores `old_str` and `new_str`, so it does not establish that the edit content matches the demonstration.

For the new 98-trajectory scalar result, the apparent improvement is nine graft-only matches versus two baseline-only matches. The percentile bootstrap reports a lower bound above zero, but an exact paired McNemar/binomial test gives two-sided p = 0.0654. That is suggestive, not conventionally significant. A discrete bootstrap is brittle with only 11 discordant pairs.

### The two SWE-Gym pools are not an IID random split

The original pool uses low dataset indices and the new pool uses indices >=214. SWE-Gym was assembled from multiple generator/temperature/dataset rounds, and row-level source metadata is absent. The two pools show significantly different scalar effects: original averaged test-retest +0.0145; new -0.0017; bootstrap difference about -0.0162 with interval [-0.0321, -0.0011]. This may be real domain heterogeneity or index/source confounding. It is not safe to call the first result “replicated” merely because it repeated on the same 75 trajectories.

Task duplication is present but not catastrophic. The 173 used trajectories correspond to 121 distinct initial issue prompts; the original 75 correspond to 47 tasks, while the new 98 correspond to 87. Task-clustered intervals leave the main continuous conclusions essentially unchanged. Future reports should nevertheless cluster by underlying task (and ideally report repo-stratified effects), not only by trajectory.

### The strongest coding champion lacks a champion-matched placebo

The α sweep has position-shuffled placebos, but `E-champion` does not. If the running confirmation is positive, the next causal gate is the same fixed layer map with wrong-history/same-token or shuffled write-time state. Otherwise a layer-specific activation perturbation, not recovered continuity, could explain the lift.

### The final cross-architecture gate was not uniformly applied

The preregistered QK-norm sign hypothesis was falsified by Mistral's positive referent result without QK norm, no 16-model regression was completed, and the only within-Qwen dense/MoE referent comparison is inconclusive because both relevant banked intervals span zero. Qwen2.5's saved result used the older absolute competence floor and excluded nine plants, whereas the later frozen rule was relative. Its large negative is unlikely to disappear, but exact cross-model estimates do not share one final inclusion rule.

### “Content-specificity” does not yet isolate hidden history

The current placebos compare correct old values with shuffled tokens, other conversations, or Gaussian noise. These are much farther from fresh values than the correct same-token old values are. In particular, the Gaussian control is matched to the norm of the source value, not to the norm/covariance of the actual treatment perturbation `(V_old - V_fresh)`. The shuffle substitutes other source states and is not guaranteed to be a derangement. Thus real > placebo can reflect lexical/token identity, geometric proximity, or simply a much smaller perturbation—not information about the evicted history.

The decisive control is **same summary text, same token identity, different hidden history**. Generate or teacher-force identical summary tokens after two counterfactual histories and transplant from the wrong history. Also add treatment-delta-matched controls: permute observed deltas with enforced derangement, or sample noise matched per layer/head to delta norm and covariance. Report perturbation norms and output KL alongside task scores. Until then, “content specificity” is not causally established.

## Statistical reconstruction of the latest coding evidence

Numbers independently recomputed from committed files:

The reported E-B quantity is a mean log-probability difference in nats/token. It is useful and interpretable, but it is not mathematically bounded; descriptions of it as a “bounded metric” should be replaced by “pre-specified continuous metric” or an explicitly bounded transform. With only 18 synthetic conversation clusters, intervals should be paired with a smallest effect size of interest or equivalence bound before calling a result definitive.

- Original 75, run 1: scalar E-B +0.0156, interval about [+0.005, +0.027].
- Same 75, clean brief rerun: +0.0133, about [+0.002, +0.026]. These are test-retest measurements, not independent sample size.
- Average the two measurements per trajectory: +0.01449, bootstrap [+0.0041, +0.0257].
- New disjoint-index pool, 98: scalar -0.00169, [-0.0135, +0.0092].
- All 173 unique trajectories, averaging repeats: +0.00532, [-0.00274, +0.01313].
- Pool difference (new minus original): -0.01618, approximately [-0.03205, -0.00107].
- In-domain champion, held-out eval 57: +0.01174 vs B, [+0.0063, +0.0172], 44/57 positive.
- Champion minus scalar on the same held-out 57: +0.0041, [-0.0047, +0.0129]. Thus the champion clears baseline but does not yet prove it is better than scalar.
- The full-98 champion-minus-scalar CI includes the 41 trajectories used to choose regions and is therefore not a confirmatory head-to-head. Random half-splits of the same selected pool do not remove this circularity.
- Repo-stratified champion means on held-out 57 were positive in all eight represented repos, though small for Project-MONAI. That is encouraging and argues against a single-repo artifact.

The running fixed-champion evaluation on the untouched original 75 is therefore highly informative. Interpret it as follows:

- If champion-B clears zero **and** champion-scalar is positive: a small in-domain layer-selected imitation-likelihood effect has replicated across the two index/source pools.
- If champion-B clears zero but champion-scalar does not: evidence supports “some graft in this map helps relative to B,” but not that tuning added value over the scalar.
- If champion-B spans zero: the held-out-57 win was pool-specific/selection-fragile.
- In all cases, no causal semantic interpretation is earned without a champion-matched wrong-history placebo, and no agent-performance claim is earned without executing actions/tasks.

## Literature: what is actually novel

### Directly prior to the broad question

**MEMENTO (April 2026)** is the closest and most important prior. It trains models to generate compact “mementos,” masks/evicts the preceding reasoning block, and continues while retaining the memento's original KV states. Its restart ablation re-prefills the same memento text and loses 15.3 percentage points on AIME24. This directly demonstrates a useful implicit KV channel beyond summary text. It uses full KV state and compaction-aware training, not the repo's untrained V-only graft.

**Models Take Notes at Prefill (June 2026)** shows that prefill writes conclusions onto downstream token states, naive local KV edits fail because conclusions are memoized elsewhere, and cached notes can be RoPE-repositioned/spliced across contexts. It is highly relevant to why this repo's token-local/post-hoc edit can fail. See [arXiv:2606.17107](https://arxiv.org/abs/2606.17107).

### Adjacent but not identical

- [CacheBlend](https://arxiv.org/abs/2405.16444) combines precomputed chunks and selectively recomputes a small fraction of KV to recover full-prefill quality. It suggests repair/recompute is more coherent than raw old-V/fresh-K fusion.
- [Gist Tokens](https://arxiv.org/abs/2304.08467) trains summary tokens as latent compressors.
- [Cache-to-Cache](https://arxiv.org/abs/2510.03215) learns projection/fusion of KV states for semantic communication between models.
- KV eviction/compression work (H2O, StreamingLLM, SnapKV, etc.) establishes that selected cached states can retain downstream utility, but generally does not isolate re-encoding across a natural-language summary boundary.

### Defensible novelty statement

Do not claim that useful information beyond text summaries in KV state was unknown. A defensible statement is:

> Recent work shows that generation-time KV states can form a useful implicit channel across learned compaction. We test whether a simpler, training-free intervention—post-hoc replacement of fresh compacted-context values with aligned write-time values while keeping fresh keys—recovers semantic continuity in an ordinary instruction model. On controlled held-out probes it generally does not; a small coding-trajectory proxy may survive in-domain layer selection.

The repo may still be novel in the exact V-only intervention and its referent/sense/stance instrument, but the instrument did not yield a robust positive and the broader premise is prior art.

## Why the naive method likely fails—and how to make it work

### 1. Preserve a coherent state, not half of one

K and V are joint projections of the same contextual residual. Keys get explicit RoPE, but values are not semantically position-free; their input hidden states already encode position/history. Mixing old V with fresh K creates a state pair the model never saw in training. Test full original K+V summary states with exact re-rotation, using a matched fresh control at the identical packed positions.

### 2. Match kernel/decomposition in the control

The project itself observed that batched prefill and stepwise decode produce different activations. The H-pack vs B-min-pack contrast compares generation-time/stepwise summary KVs with a batched fresh prefill. Build a **fresh-stepwise restart**: teacher-force the identical summary tokens one at a time after only the compacted prefix, then compare it to the original history-conditioned stepwise states. This isolates history conditioning from kernel shape.

### 3. Factor summary and tail

Run a 2x2 token-region factorial: no graft, summary-only, tail-only, both. My leading hypothesis for the coding result is that retained-tail values, rich in identifiers/paths/tool state, matter more than the summary values. The existing compression sweep cannot adjudicate this because three conditions reconstructed the wrong request.

### 4. Move from post-hoc replacement to forward-consistent repair

E-post changes cached values only after all summary/tail representations have been computed. Try the already-conceived interleaved version, or CacheBlend-style selective recomputation: inject/retain states at a lower layer and recompute downstream representations/upper-layer KVs. Even a small boundary-repair window can restore consistency.

### 5. Target downstream “notes,” not every matching token

Models Take Notes predicts that conclusions concentrate in downstream aggregators/delimiters, not the source token itself. Profile causal positions, not merely layers/heads. Preserve or recompute a small set of summary-end, message-boundary, tool-result-end, and plan/decision tokens. A position × layer map is more principled than uniform exact-twin grafting.

### 6. Train the behavior

MEMENTO's success is not an accidental property of arbitrary summaries; it trains the model to compress into states it will later use. A lightweight version could fine-tune an 8B/14B coding model on block→summary→masked-continuation examples, keeping original summary KV at inference. Even LoRA/SFT may be more promising than further α sweeps on an untrained 30B.

### 7. Learn a small adapter/gate

Instead of `V_old` directly, learn a low-rank map or gate from `(V_old, V_fresh, layer, token type)` to a repaired value, trained on next-action likelihood with strict task-held-out validation. This follows C2C/latent-compression evidence while keeping compute small. Pre-register degrees of freedom; otherwise it becomes a large selection surface.

## A realistic coding-agent experiment worth doing

Yes, it is worth doing—but only after changing the experimental unit from imported next-action imitation to a **model-native, environment-forked continuation**.

### Phase 0: capability and sensitivity gate

- Choose an agent/model pair capable of solving the task source under full context. A coding-specialized 14B–32B model may beat the current general Qwen checkpoint at lower cost.
- Use real repository tasks but filter on a discovery set: full-context solve rate roughly 30–70%, and a production-faithful compacted baseline measurably worse. Do not scale a source with A≈0 or A≈B.
- Candidate sources: easy SWE-Gym/SWE-smith tasks, small real PR reproductions, or curated repository tasks with deterministic tests. The tasks should naturally require multiple tool turns and exceed the compaction threshold.

### Phase 1: fork at an actual compaction boundary

For each model-native episode:

1. Run one common prefix with the test model in a real container until a standardized compaction trigger.
2. Snapshot both the model cache and repository/container state.
3. Have the same model generate the summary while full history is visible.
4. Fork identical environment snapshots into A (full), B (fresh production compaction), E (candidate state retention), and P (wrong-history matched placebo).
5. Continue each branch with identical tool access, budgets, decoding policy, and random seed schedule.

This paired fork is far more efficient and controlled than starting independent episodes from scratch. Every arm shares the difficult early investigation.

### Outcomes

Primary: tests/resolve rate or a pre-registered graded test score.  
Secondary: progress toward gold patch, regression count, repeated failed actions, action edit distance, and log-probability of the next few *model-native* actions.  
Mechanism: summary-only vs tail-only, correct vs wrong-history, full KV vs V-only, and state-use attention/readout.

### Statistical design

- Cluster at underlying issue/task, not trajectory.
- Use multiple seeds per task only as within-task repeats.
- Freeze task set and intervention after a discovery set; evaluate on a task-held-out test set.
- Report paired risk difference and exact/randomization intervals. A binary resolve-rate study needs substantially more than 10 tasks unless the effect is large; begin with a 10–15 task canary solely to establish baseline damage and operational viability.
- Do not select tasks by observing E. Selection may use only task metadata and A/B capability/sensitivity on a separate discovery set.

### Cost-conscious ladder

1. Offline multi-step continuation replay on saved **model-native** trajectories (score the next 3–5 action turns, not one teacher action).
2. Ten-task live forked canary; stop if B does not underperform A or the model cannot solve.
3. Thirty-to-fifty task held-out paired study if the canary shows both damage and plausible recovery.

## Final interpretation

The amateur nature of the project does not make it worthless. Its strongest scientific achievement is that it eventually falsified its own attractive story. The identity work, incident archive, render banking on the synthetic line, and willingness to quarantine contaminated results are unusually valuable. But the project repeatedly converted “there is information in the state” into “this particular transplant should improve performance.” Those are different claims.

The evidence now supports this synthesis:

> Generation-time cache state can carry useful information beyond summary text; recent literature demonstrates that directly. This repository has not yet shown that a naive, training-free, post-hoc old-value/fresh-key graft reliably exposes that information as better semantic recovery: its pooled synthetic null hides a source reversal, and its compression-severity evidence is partly invalid. There may be a small, layer-localized coding-domain signal under aggressive compaction, but it is currently an imitation/probability proxy and still requires out-of-pool confirmation plus a matched causal placebo. The promising path is coherent full-state retention, controlled restart comparisons, downstream-note targeting, and eventually compaction-aware training—not more indiscriminate value mixing.
