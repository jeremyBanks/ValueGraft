_The day advanced the ValueGraft semantic-continuity experiment from validated
cache-surgery machinery to an initial 4B batch, while refining controlled
contrasts for separating summary encoding, value payloads, cache addresses, and
correspondence. Early results are suggestive but provisional, with continuation
metrics noisy and leakage controls still shaping interpretation._

**Participants/contributors:** User. No exact assistant model identifier,
version, or reasoning-effort level is stated in the source notes.

The experiment tests whether write-time KV state preserves conversational
meaning across compaction better than freshly re-encoding a summary and recent
tail. The planned comparison remains:

- A: full-context oracle.
- B: standard summary-plus-tail compaction baseline.
- C: gapped retention of original sink, tail, and in-context summary KV.
- D: retained tail without the summary.
- E-post/E-inter: fresh keys with transplanted old values, varying graft
  strength α.
- H-gap/H-pack: minimal retention of an in-context-encoded summary, compared
  with B-min, which uses identical summary text freshly encoded.
- G/SoftGraft: optional attention-mediated retrieval of old values for
  paraphrased summary content.

The validated L0–L4 ladder established cache identity and surgery correctness,
including correction of batched-versus-single-token kernel differences, unstable
Qwen `<think>` template behavior, and summary/tail alignment after reordering.
An isolated planted-sense test showed old values contributing approximately +0.8
nats toward the intended sense at α=1, compared with +1.9 for K+V transfer and
+3.8 for the full-context oracle; the value effect was monotonic in α. The
synthetic corpus contains 12 scenarios and 120 validated plants. After repair,
all five probe categories had 24/24 clean instances for tail contamination,
although harmless leakage remained in early sections. Natural conversations were
generated separately with the subject model so held-out continuation tests
remain model-native.

Initial full-pipeline observations on one scenario were directional: D closed
63% of the A–B continuation gap, E-inter at α=1 closed 33%, C approximately
matched B, and E-post degraded as α increased. H-gap slightly exceeded B-min.
With four scenarios, referent probes favored C and H-gap (6/8 each versus 4/8
for B), while sense probes modestly favored H-gap (3/8 versus 2/8 for B); E had
not yet surpassed B. Continuation scores were noisy and generally below B, so
continuation prediction is currently secondary to controlled probes.
Evicted-fact results showed summary leakage and must be quarantined using the
planned six-class leakage classifier. Stance probes require semantic judging and
paraphrase checks because keyword matching can incorrectly treat mention of a
rejected option as compliance.

The most informative near-term contrast is H versus B-min: identical summary
text, differing only in whether it was encoded with the original history
available. H versus C measures the marginal contribution of authentic recent
tail state, while E versus C isolates fresh-key/old-value payloads from retained
addresses. G should remain optional until the main A–E and H contrasts are under
control; its attention-based retrieval avoids unsound nearest-neighbor
comparison in value space and should include entropy gating and sink exclusion
if implemented.

The first complete 4B batch was reported healthy at 10/19 conversations, with no
observed errors and supplement arms queued after the main batch. The 30B-A3B
model remains the intended primary robustness result, subject to memory and
runtime constraints. Statistical power is expected to come mainly from more
conversations, probes, and seeds rather than model size alone. Any scale-up
should follow a short decision memo: choose a larger dense model if the local
effect is clear, or spend the budget on replication and tighter intervals if the
effect is marginal. A later coding-agent phase could provide realism through
tool-call-boundary compaction, behavioral probes, and task outcomes, but it
should wait for controlled local evidence.

Persistent methodological rules include temperature-zero evaluation, fp16 caches
even with 4-bit weights, exact model/library/quantization/seed pinning,
automatic summary-leakage audits, and no claims from configurations that have
not passed the identity ladder. Gapped-cache out-of-distribution behavior and
fresh-key/old-value incompatibility must be measured rather than tuned away;
non-monotonic α curves or null results remain valid findings. Operationally,
long commands should preserve complete output with `tee` before filtering, use
unbuffered logging for detached jobs, be bracketed with timestamps, and
serialize GPU-bound work when concurrency only increases memory pressure.
