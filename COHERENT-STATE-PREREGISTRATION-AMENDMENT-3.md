# Coherent summary state: Amendment 3 — independent external wrong-history controls

**Frozen:** 2026-07-11, before any 30B semantic arm outcome from the corrected
position-preserving apparatus. This file is additive. All prior preregistrations,
technical failures, and ladder artifacts remain unchanged as the development record.

## Why the donor map must change

The original wrong-history map arranged the twelve scored target conversations as
two six-cycles. Each target therefore also supplied the donor content for another
target's `G_wrong` arm. Although each row was clustered by scored target, the rows
were not independent conversation units: adjacent outcomes in a donor cycle were
functions of overlapping conversation data. An ordinary conversation-level t
interval or independent conversation bootstrap did not have its stated nominal
interpretation for the co-primary `GW` contrast. At N=6 there was only one connected
donor cycle.

This issue was identified from the frozen map and analysis code, not from a semantic
result. No 30B gapped semantic outcome exists.

No donor is reused and no donor is a scored target. The complete map and SHA-256 of
every donor file are part of the run fingerprint. The driver loads these committed
files directly; they are not regenerated or adaptively selected. The checkpoint
persists the donor ID, path, file hash, complete source token IDs, replacement pools,
and decoded diagnostic before scoring.

The external files' exact recorded author strings are fingerprinted and reported:
`sonnet` (c13–c15), `opus` (c16–c18), `codex-gpt5.5` (c25–c27), and
`sonnet-render` (c28–c30). They are authored controls, not native conversations
generated by the 30B experimental subject. Their role is solely to provide unrelated
content-token pools for the already artificial, exact-length donor-slot intervention.
All target structure, system, retained tail, request/header, summary positions, and
visible destination tokens remain those of the scored target.

With disjoint target/donor pairs, each `GW_i` is a function of one scored target and
one unique exogenous fixed control stimulus. Conversation-pair clustering is again
coherent for this fixed benchmark. Student-t and bootstrap intervals describe
across-pair variation under an exchangeability assumption; they are not guaranteed
population coverage for arbitrary conversations or arbitrary wrong histories.

## Claim boundary

A positive co-primary intersection supports only:

> Correct-history summary state improved downstream use relative both to fresh
> encoding and to the prespecified exact-position external donor-slot controls,
> under position-preserving compaction in this fixed benchmark.

It does not isolate the planted fact, establish superiority to every plausible
wrong history, or eliminate congruence/surprisal as part of `G_correct-G_wrong`.
Wrong-summary NLL and decoded-control quality remain mandatory reporting diagnostics.

frozen N=12 endpoint. Technical or regime failure labels retain precedence.
